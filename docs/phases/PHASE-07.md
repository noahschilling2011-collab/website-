# Phase 7 — Oberfläche neu

## Ziel
Die eine `index.html` hat ihre Grenze erreicht. Jetzt eine richtige App.

Ab hier ist ein Build-Step erlaubt — vorher nicht.

## Was gebaut wird
- Frontend mit Build-Step. Konkrete Wahl wird **hier** getroffen, nicht früher.
- Ansichten: Konversationen, Aufgaben, Werkzeuge/Freigaben, Gedächtnis,
  Einstellungen.
- Das bisherige Aussehen bleibt: dunkel, Glas, eine Akzentfarbe, ruhige
  Bewegung.

## Definition of Done
1. Alles, was die alte `index.html` konnte, geht weiter.
2. Erster sinnvoller Inhalt unter zwei Sekunden auf gedrosseltem Netz.
3. Bedienbar per Tastatur, sichtbare Fokusringe.
4. Ein Build-Befehl, im README dokumentiert.
